# DII Suite – Αξιολόγηση καθυστερήσεων σε εργοτάξιο παθητικού κτιρίου

Εφαρμογή της διπλωματικής εργασίας «Ανάλυση και Αξιολόγηση Καθυστερήσεων σε Εργοτάξιο Παθητικού Κτιρίου μέσα από Πραγματικές Συνθήκες και Μετρήσεις» (Αναστάσιος Β. Πανταζής, Σχολή Μηχανολόγων Μηχανικών ΕΜΠ, 2026).

Περιλαμβάνει τρία εργαλεία που χρησιμοποιούνται διαδοχικά:

1. **Ενεργές εργασίες** – ποιες εργασίες και ποια συνεργεία είναι ενεργά σε μια ημερομηνία, με διάγραμμα Gantt.
2. **Domino Effect** – ποιες εργασίες επηρεάζονται από μια καθυστέρηση και πώς μετατοπίζεται το χρονοδιάγραμμα.
3. **Delay Impact Index (DII)** – αξιολόγηση της κρισιμότητας κάθε καθυστέρησης:
   `DII = w1·f_t + w2·f_c + w3·f_d + w4·f_r` (στην αρχική εκδοχή όλα τα βάρη = 1).

## Εκτέλεση τοπικά
```
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Δομή
```
streamlit_app.py   αρχική σελίδα και πλοήγηση
common.py          κοινές σταθερές, παραδείγματα, βοηθητικές συναρτήσεις
tools/energes.py   εργαλείο 1 – ενεργές εργασίες
tools/domino.py    εργαλείο 2 – domino effect
tools/dii.py       εργαλείο 3 – δείκτης DII
```
